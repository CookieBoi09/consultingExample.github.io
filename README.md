# Northstar ML consulting site

A responsive, multi-page consulting website for an independent machine learning consultancy.

## Pages

- Home: services, differentiators, and calls to action
- About: point of view, principles, and ideal client fit
- Contact: structured project inquiry that opens a pre-filled GitHub issue

The site is built with plain HTML, CSS, and JavaScript so it deploys directly through GitHub Pages with no build step.
